JC3248W535C touch display module
Product specification

An ESP32-S3 module with a 3.5 inch 320×480 capacitive touch display, microSD slot and speaker output, running a suite of twelve apps: a game hub with eight games, a WiFi weather clock, a photo and video player, a music player and an LVGL demo. Every item below is marked verified when it was tested on the real board, or unverified when it was not.

Software platform

Toolchain, libraries and the settings that matter.

Toolchain

  • PlatformIO with the pioarduino platform (Arduino core 3.x). The stock espressif32 platform has core 2.x and the display library does not build on it.
  • Board esp32-s3-devkitc-1, 16 MB flash, QIO flash mode, OPI PSRAM.
  • Flags: -DBOARD_HAS_PSRAM -DARDUINO_USB_MODE=1 -DARDUINO_USB_CDC_ON_BOOT=1.
  • esptool must run with PlatformIO’s own Python (~/.platformio/penv/bin/python).

Libraries

  • GFX Library for Arduino ^1.5.6 (display, canvas)
  • LVGL ^9.2.2, configured with build flags, no lv_conf.h
  • ArduinoJson ^7.2.0 (weather)
  • JPEGDEC ^1.7.0 (photos and MJPEG video)
  • ESP32-audioI2S from its git repository (music), needs -DCORE_DEBUG_LEVEL=0

Display pipeline

  • All drawing goes into a 320×480 RGB565 canvas in PSRAM, then one flush() sends the frame. Drawing straight to the panel garbles the image on this controller.
  • Flush only when something changed, at most every ~30 ms. This is what makes touch feel instant.
  • Landscape media (480×320) is rotated 90° in software.

Touch handling

  • Read 8 bytes after writing B5 AB A5 5A 00 00 00 08; byte 1 is the touch count, bytes 2–5 hold X and Y.
  • The controller drops out for a few reads while a finger is down, so a release means 6 empty reads in a row.
  • A new press counts only after a full lift.

How it behaves

  • Tapping a tile plays a grow-to-fullscreen animation, makes that slot the boot partition, and restarts (about one second).
  • Each tile shows the game’s saved best score, read from the game’s own NVS namespace. The last-played game has a white outline.
  • Every game sets the launcher as the next boot app as soon as it starts, so a reset or power-up always lands on the hub.

Returning to the hub

  • Hold the top-left corner for 1.5 s in any game except Paint.
  • Paint: on-screen HOME button, tap twice (the first tap warns that the drawing will be lost).
  • Backup: hold the BOOT button for 0.7 s.
  • Run standalone, an app ignores these gestures.

UI design rules learned on this hardware

These came from testing, and every game follows them.

Do

  • Use large on-screen buttons that act on press.
  • Require a full finger lift between presses.
  • Make keyboards about 320 px tall with a 20 pt key font.
  • Flush the canvas only when something changed.
  • Show a clear status line and confirm destructive actions (Paint HOME needs two taps).

Avoid

  • Swipe-only controls. A full-frame redraw can miss part of a swipe.
  • Treating three empty touch reads as a release.
  • Drawing directly to the panel instead of through the canvas.
  • Blocking HTTP calls in the UI loop; use a worker task.
  • Names such as TX or stat that clash with Arduino or libc symbols.

Build, flash and extend

Run from the repository root.

Install the whole hub

tools/flash_hub.sh            # builds and flashes the launcher, partition table and all games
                              # auto-detects /dev/cu.usbmodem*

Flash a single app

pio run -e tetris -t upload --upload-port /dev/cu.usbmodem101
pio device monitor

Flashing one app on its own overwrites the launcher slot. Run tools/flash_hub.sh to restore the hub. If an upload will not start, hold BOOT, tap RESET, release BOOT, and retry.

Add a game

  • Create examples/<name>/main.cpp and an [env:<name>] in platformio.ini with build_src_filter = -<*> +<<name>/>.
  • Include ../common/hub_home.h and wrap the touch read so it calls hubTouchNote().
  • Add a tile in examples/hub/main.cpp and the name in tools/flash_hub.sh. Slot offsets are 0x1B0000 + (N-1) × 0x100000.

Known limitations

What to expect.

  • One touch point only. Multi-touch is not supported by the firmware.
  • The display is portrait only, and landscape media is rotated in software.
  • The built-in font has no CJK glyphs, so non-ASCII track names show as “Track N”.
  • No built-in speaker. Sound needs a 4–8 Ω speaker on the JST 1.25 connector.
  • Bluetooth is LE only, so the module cannot act as a Bluetooth speaker or play to Bluetooth headphones.
  • Going from a game back to the hub restarts the chip, so there is about a one-second black gap.
  • Switching to the hub from Paint loses an unsaved drawing.
  • Standalone samples use the same partition table once the hub is installed, so the launcher slot (1.625 MB) is the size limit for a single standalone app.
